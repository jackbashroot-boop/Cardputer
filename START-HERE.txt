==============================================================================
 C A R D P U T E R   E M U    —    start here
==============================================================================

An emulator for the M5Stack Cardputer (v1.0 / v1.1) and Cardputer-Adv: the real
240x135 panel, the 56-key matrix, the audio path, IMU, IR, microSD, Wi-Fi, the
battery, plus a hot-pluggable M5Stack Grove / CAP module rack and a flash panel
where you can install your own programs.

You need Python 3.9 or newer. Nothing else: no pip, no node, no compiler, no
admin rights. Get Python from https://www.python.org/downloads/ (on Windows tick
"Add Python to PATH").

------------------------------------------------------------------------------
 1. INSTALL (about 10 seconds, does everything)
------------------------------------------------------------------------------
    Windows        double-click        install.bat
    macOS          double-click        install.command
    Linux          double-click        install.sh
                   (or in a terminal:  python3 install.py)

The installer checks Python, creates the runtime data folder, builds the UI
(cardputer.html) from the sources, offers a desktop / Start-menu shortcut, and
then self-tests the whole thing — it starts the local server, asks it for its
version, fetches the page, and (if Playwright happens to be installed) drives it
in a headless browser. If anything is broken it tells you before you start.

------------------------------------------------------------------------------
 2. RUN
------------------------------------------------------------------------------
    Windows        run.bat            (or the shortcut on your desktop)
    macOS          run.command
    Linux          run.sh             (or:  python3 run.py )

The emulator opens in your browser at http://127.0.0.1:8787/ — a local server,
nothing leaves your machine.

  No server at all?  Open cardputer.html directly in any modern browser. It is
  the whole emulator in one file (single-player mode: no core updates, no HTTP
  proxy, but the device, the rack and the flash panel all work).

------------------------------------------------------------------------------
 3. WHAT TO TRY FIRST
------------------------------------------------------------------------------
  * Click the SKU pill in the top bar (Cardputer v1.0 -> v1.1 -> Adv). Watch the
    keyboard controller, IMU, 3.5 mm jack, EXT header and Grove 5 V rail change
    and the modules that no longer fit get unplugged with a reason.
  * Modules tab: plug in a Grove ENV III, then launch "ENV Mon" from the device
    screen with the arrow keys and ENTER. Pull the unit out while the app runs.
  * Flash tab: paste a program into the editor, press "install & run". It is a
    real program, saved, and it comes back after a reload.
  * Flash tab: drop an ESP32-S3 .bin to see the partition table, download mode
    and the erase/write/verify cycle.
  * Bench tab: thermal model, task watchdog, microSD browser, IR capture, Wi-Fi scan.

------------------------------------------------------------------------------
 4. UPDATES
------------------------------------------------------------------------------
  A release feed ships inside this folder (updates/). The launcher checks it on
  start; you can also do it by hand:

      python3 run.py --check        # what is available
      python3 run.py --update       # download, verify (SHA-256), install
      python3 run.py --rollback     # go back one build
      python3 run.py --status       # version, channel, snapshots

------------------------------------------------------------------------------
 5. FILES
------------------------------------------------------------------------------
  install.py            installer + self-test (this is the only thing you need to run)
  run.py                the launcher (serves the UI, handles updates)
  cardputer.html        the whole emulator as one file
  src/                  UI + firmware sources (rebuild with: python3 build.py)
  cardputer/            Python side of the launcher (stdlib only)
  docs/                 FLASH.md (install programs), ACCURACY.md (vs QEMU/Wokwi),
                        MODULES.md (50 modules), UPDATES.md, APPS.md
  art/                  the hero render of the device
  tests/ tools/         test suites and the quality gate (optional)

Troubleshooting: if the port is busy the launcher picks the next free one and
prints the URL. If Python is missing, install it and run the installer again.
